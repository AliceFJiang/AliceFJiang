## About Me

Hi, I'm Alice. I am an engineering student interested in robotics, intelligent systems, and scientific machine learning. I like learning by building: turning lab notes, experiments, and half-formed questions into notebooks that can be read again later.

My current work lives around ROS, computer vision, model training, and research-style documentation. I care about clear explanations as much as working code, because a good project should help the next person understand the idea, not only reproduce the result.

## Research Interests

- Robotics software systems, especially ROS 1 / ROS 2 workflows
- Computer vision for gesture, posture, and human-machine interaction
- Machine learning for scientific prediction and materials-related problems
- Reproducible notebooks, lab documentation, and explainable technical writing
- Data-driven modeling, evaluation, and visualization
